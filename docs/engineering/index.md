# Engineering Documentation

This directory contains maintained engineering standards.

- `frontend.md`: UI components, Tailwind, shadcn, accessibility, forms, and localization.
- `testing.md`: Verification commands, automated tests, browser checks, and regression strategy.
- `security.md`: Secrets, authorization, validation, sensitive data, and security boundaries.

## Maintenance Rules

- Keep each document focused on one subject.
- Avoid duplicating rules from `AGENTS.md`.
- Link to the authoritative document instead of copying the same policy into multiple files.
- Update documentation when implementation or established conventions materially change.
- Delete obsolete instructions instead of continually appending exceptions.
- Do not require agents to read every document for every task.
